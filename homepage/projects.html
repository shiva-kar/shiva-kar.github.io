LEARNING BY BUILDING

Projects and experiments.

I learn best by making things, testing them, and figuring out the parts I don’t understand yet. Here are a couple of projects from that process.

C · POSIX · CMake PROJECT 01

SXSHELL

A Unix-like shell written from scratch in C. It supports built-in commands, PATH-based command lookup, quoting and escaping, I/O redirection, multi-command pipelines, persistent history, and shell variable expansion.

Built to understand process management, file descriptors, and the system calls behind terminal commands.

C · Raw sockets · HTTP PROJECT 02

Custom HTTP Server

A lightweight HTTP server in C, currently in progress, focused on using raw sockets and learning how requests are received, parsed, and answered.

The goal is to learn more about networking fundamentals by implementing the request-response flow directly.
