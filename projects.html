Built PROJECT 01

SXSHELL

A Unix-like shell written from scratch in C. It supports built-in commands, PATH-based command lookup, quoting and escaping, I/O redirection, multi-command pipelines, persistent history, and shell variable expansion.

Built to understand process management, file descriptors, and the system calls behind terminal commands.

  • Uses fork(), execvp(), waitpid(), pipe(), and dup2() for process execution and multi-stage pipelines
  • Custom tokenizer handling single/double quotes, backslash escaping, and environment variable expansion
  • Persistent command history and signal handling (SIGINT)

C · Raw sockets · HTTP
In Progress PROJECT 02

Custom HTTP Server

A lightweight HTTP/1.1 server in C, currently in progress, focused on using raw TCP sockets and learning how requests are received, parsed, and answered.

The goal is to learn more about networking fundamentals by implementing the request-response flow directly.

  • POSIX socket lifecycle: socket(), bind(), listen(), accept(), recv(), and send()
  • Zero-dependency HTTP request line, header parser, and status-code response builder
  • Static file serving with MIME type detection and concurrent client connection handling
