Custom Garbage Collector

A custom garbage collector in C built to understand manual memory management, heap allocation internals, and automatic object reachability tracking.

Explores mark-and-sweep collection, root pointer tracing, and allocation metadata at the pointer level.

  • Tracks dynamically allocated objects via an intrusive metadata header and allocation list
  • Mark phase traverses reachable object graphs from registered stack/root pointers
  • Sweep phase reclaims unmarked heap blocks and prevents memory leaks
