## Overview

This repository hosts the static portfolio website for Shiva Kar. It showcases Java backend engineering projects (Spring Boot, PostgreSQL, Redis), systems programming (SXSHELL in C), and open-source contributions to the Godot Engine.

The site is built with vanilla HTML5, CSS3, and JavaScript, with Bootstrap 5 used for responsive layout utilities. It requires no build step or node dependency installation.

## Project Structure

```
.
├── index.html          # Landing page (hero, engineering areas, featured work preview)
├── projects.html       # Detailed architecture & technical specs for projects
├── opensource.html     # Pull request log & summary of Godot Engine contributions
├── about.html          # Education, coursework, certifications, and background
├── styles.css          # Design tokens, typography, layout, and dark theme support
├── script.js           # Theme toggle, interactive terminal, and data sync
├── data.json           # Structured portfolio data source
└── Shiva_Kar_Resume.pdf # Downloadable resume
```

## Running Locally

Because the project is purely static, you can serve it with any local HTTP server:

```bash
# Python 3
python -m http.server 8000

# Node (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
